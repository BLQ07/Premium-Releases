# Premium — автоподдержка МТС Premium

Публичный репозиторий для скачивания APK-релизов приложения **МТС Premium — автоподдержка**.

## Функции

- Автоподдержка подписки **МТС Premium** промокодами **0 ₽** из Telegram-канала.
- Несколько аккаунтов МТС ID с переключением.
- Контроль остатка и статуса подписки.
- Автопродление при достижении порога трафика.
- Прокси-маршрутизация для защиты аккаунтов.
- Фоновая работа по расписанию, уведомления, виджет.

## Используемое

- Android, Java.
- Telegram-канал с промокодами.
- Мобильные и веб-API МТС и Kion.

## Установка

1. Скачайте `app-release.apk` из раздела **Releases**.
2. Разрешите установку из неизвестных источников на устройстве.
3. Установите APK и запустите приложение.
4. Пройдите онбординг и добавьте аккаунт(ы) МТС ID.
