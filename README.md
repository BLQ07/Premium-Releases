# Premium — автоподдержка МТС Premium

Репозиторий для скачивания готовых сборок приложения **МТС Premium — автоподдержка**.

## Для чего это

Приложение автоматически поддерживает подписку **МТС Premium** промокодами из Telegram-канала: следит за остатком, продлевает подписку при достижении порога, следит за несколькими аккаунтами.

## Доступные версии

| Платформа | Что скачать | Как запускать |
|---|---|---|
| Android | APK (раздел Releases) | установить файл и открыть |
| Windows | GUI — zip | распаковать, запустить `Premium.exe` |
| Windows | Терминал — zip | запустить `PremiumTui.exe` в командной строке |
| Windows | Установщик exe | запустить, следовать мастеру установки |
| Linux | GUI — tar.gz | запустить `Premium/bin/Premium` |
| Linux | Терминал — tar.gz | запустить `PremiumTui/bin/PremiumTui` |

## Что умеет

- Автоподдержка подписки **МТС Premium** промокодами **0 ₽** из Telegram-канала.
- Несколько аккаунтов МТС ID с переключением.
- Контроль остатка и статуса подписки.
- Автопродление при достижении порога трафика.
- Фоновая работа по расписанию, уведомления.

## Установка

**Android**
1. Скачайте `app-release.apk` из раздела **Releases**.
2. Разрешите установку из неизвестных источников.
3. Установите и откройте приложение, добавьте аккаунт МТС ID.

**Windows / Linux**
1. Скачайте архив нужной версии и распакуйте.
2. Запустите программу (см. таблицу выше).
3. В программе добавьте аккаунт через вход МТС ID (откроется браузер).
